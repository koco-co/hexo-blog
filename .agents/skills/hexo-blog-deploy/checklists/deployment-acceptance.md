# 部署语义验收清单

机械预检由 `audit.mjs` 保证；本清单只检查授权、实际发布和线上语义。

## 授权与范围

- 用户明确区分了准备报告和本次实际部署。
- 展示并确认的目标、分支、路由和命令与实际动作完全一致。
- 没有把部署授权扩张为提交、清理、强推、主题修复、CI 修改或权限变更。
- 报告列出了所有已经发生的外部副作用。

## 构建与候选版本

- 构建使用当前源文件和当前主题状态，没有用旧 `public/` 代替。
- 构建后的文章 URL、关键入口和本次变更页面可定位。
- UI 或前端功能变更完成了真实浏览器、移动视口和适用的 PJAX 验收。
- 第三方服务失败时站点核心内容仍可使用。

## 发布结果

- Local 路由验证了 `npm run deploy` 的真实退出结果。
- CI 路由验证了工作流运行和 Pages/目标环境状态，不只验证源码推送。
- 线上验证访问了公开站点的本次变更路由，而不是本地服务。
- 缓存、CDN、构建、推送和产品行为问题被分层判断。

## 报告质量

- “预检通过”“已部署”“线上已验证”分别有独立证据。
- 未运行的远程、浏览器、移动端或第三方场景明确标为未验证。
- 任何 Token、Cookie、API Key、认证头、带凭据 URL 或私人文件名均未出现。
- 失败后没有自动重试、清理、强推或再次部署。
