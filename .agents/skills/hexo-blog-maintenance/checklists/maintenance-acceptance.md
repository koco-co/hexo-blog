# 维护语义验收清单

只检查无法由 `audit.mjs`、语法检查或 Hexo 构建可靠保证的项目。

## 内容

- 标题、摘要、章节层级与目标读者一致，没有空泛占位或事实断层。
- 普通 H2/H3 是简短的对象、动作或边界名，通常不超过 15 个字符；原因、步骤、结论和失败边界在正文或图表中解释，问句只在 `常见问题` 中使用。
- 标题与正文文案没有堆叠冒号/顿号概念、聊天式过程话术或内部调研说明；固定的 `常见问题`、`参考资料` 和入门路线六个 H2 未被改名。
- 正文遵循 `rules/technical-writing-style.md`：从真实对象或问题进入主题，用因果关系推进，辅助表达确实降低理解成本，没有机械教学栏目、术语堆叠、幼稚口号或无作用总结。
- 代码解释了关键动作和可观察结果；表格、图示、图片与类比各自承担适合的信息，类比说明了失效边界，图片之外保留等价文字结论。
- 外部事实有当前可信来源；历史文章没有被误当成最新规范。
- 标签、分类、图片替代文本和链接语义准确。
- Butterfly 标签的视觉用途与正文信息层级匹配，没有用空洞内容填充视觉组件。
- 加密文章、私人链接和示例没有泄露真实凭据或隐私信息。

## 视觉丰富文章

- AI 新建文章或整体视觉重构在写入前已有用户确认的“文章结构 + 标签编排预案”。
- 最终章节、标签组合、外部依赖和降级方式与确认预案一致；实质偏差有后续确认记录。
- 课程文章每个有意义的解释块都有语义对应的块级标签；H2/H3、代码、表格、列表和结构连接保留普通 Markdown 属于允许例外，且已通过 `LEARN_TOPIC_PLAIN_BODY_BLOCK` 审计。
- 课程文章没有 `学习目标`、`章节计划`、`验证方式` 等公开内部合同，没有“前置文章是……”、课程进度或能力账本文案；`course_series` 是唯一课程导航。
- 根据真实内容主动组合提示、选项、流程、关系图、补充信息、资源导航或媒体等不同视觉角色，不以固定数量代替判断。
- 同一种 `note`、`folding`、卡片或按钮没有连续主导多个章节；重复结构确有信息组织理由。
- 核心结论、关键步骤、必要命令和风险保持直接可见；折叠或隐藏区域只承载补充、答案或非关键细节。
- 普通 Markdown 保持连续阅读路径，标签移除或外部资源失败时仍能理解文章主线。
- 视觉密度在桌面、移动端和明暗主题下均可读，没有因多标签组合产生拥挤、跳动或交互冲突。

## 标签外挂

- 标签来自当前实际注册的 Butterfly 或 Tag Plugins Plus 能力，没有把历史同名标签当成当前实现。
- 标签选型服务于内容结构；视觉丰富分支落实已确认的多样组合，普通分支没有增加不必要的卡片、折叠或动画。
- 参数顺序、分隔符、大小写、容器闭合和嵌套顺序与当前源码一致。
- `btns/cell`、组合卡片、引用 ID 和 `carousel` ID 的局部关系完整且唯一。
- 没有使用配置关闭的 `issues`，也没有未经确认修改插件开关、CDN 或主题解析器。
- 外部卡片、徽章、图片、音视频和 API 失败时，核心信息仍能通过正文或普通链接理解。
- `psw` 只隐藏剧透或辅助内容，不承载真实密码、Token 或私人数据。

## 闪卡与复习

- `常见问题` 的题数来自知识密度、易混淆边界和长期复习价值，没有固定上限，也没有用重复问题制造数量。
- `answer` 便于主动回忆；`explanation` 脱离正文仍能讲清原因、过程和边界，抽象或复杂问题至少有一种合适的 Markdown 辅助表达。
- 解析没有只重复答案、罗列术语、给无注释代码、依赖没有文字兜底的图片，或使用不说明边界的类比。
- 编辑旧文章时已复查该篇所有原始 `flashcard` 定义；`flashcard_ref` 继续指向唯一原始定义，范围外遗留项只报告、不阻断无关工作。

## 配置与功能

- 改动位于正确所有权层，没有可避免的主题核心修改。
- 功能在目标页面存在时正常工作，在 DOM 缺失或第三方服务失败时安全降级。
- PJAX 首次加载和站内跳转行为一致，没有重复监听、重复节点或累积定时器。
- 搜索、评论、位置、统计等第三方功能的失败不会阻断正文浏览。

## 本地图片

- 真实渲染的封面、Markdown/HTML 图片和标签外挂图片参数使用存在的本地路径；教程代码示例不会被误判为线上依赖。
- 历史迁移图片与固定来源提交的清单在目标路径、字节数和 SHA-256 上一致，没有顺带迁移未被本博客使用的旧仓库图片。
- 新图片直接进入 `source/img/picgo-images/`，不依赖 PicGo 远程上传；图片优化、格式转换和远程仓库处置均保持独立授权边界。

## 视觉与可访问性

- 桌面和移动布局没有溢出、遮挡、跳动或不可点击区域。
- 明暗主题下文字、边框、链接和状态均可辨认。
- 键盘焦点、悬停、展开/折叠和可点击元素具有可观察反馈。
- 长标题、长代码、长链接、图片失败和空内容不会破坏布局。

## 证据与结论

- 报告说明实际访问的路由、视口、交互和失败状态。
- 截图或日志只包含完成判断所需信息，且没有秘密。
- 静态、构建、浏览器与线上结果分开陈述。
- 未运行的浏览器、移动端、第三方服务或线上场景明确列为未验证。
