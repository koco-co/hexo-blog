# 文章结构与标签编排预案示例

## 基本信息

- 文章标题：使用 uv 与 Ruff 建立现代 Python 工具链
- 文章类型：技术教程
- 目标读者：熟悉 Python 基础、准备改造项目工具链的开发者

## 整体阅读节奏

- 开篇使用一个结论型 `note`，解释性正文块继续使用 `p`/`note` 等语义标签，列表和命令保持直接可见。
- 中段在关系图、选项卡、时间线和代码之间交替，避免连续堆叠相同容器。
- 结尾先用普通列表总结，再提供链接卡片。
- 安装命令、初始化顺序、必要配置和风险始终直接可见。
- 完整配置解释、长日志和非关键变体才进入折叠区域。
