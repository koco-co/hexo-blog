# Hexo 课程验收清单

## 路线与文章地图

- [ ] 主题、版本或 Commit、零基础基线、前置、范围和毕业成果有当前来源。
- [ ] 路线经过第一次确认，文章地图经过干净上下文 Curriculum Reviewer 与第二次确认。
- [ ] 每个知识点有唯一主文章，文章依赖无环；课程编号、篇内章节、示例步骤和练习均按知识依赖顺序排列。
- [ ] 文章按宽维度拆分，没有单个 API 对应一篇短文；低频能力只在已确认的可选进阶篇汇总。
- [ ] 旧文复用有质量与版本依据；升级或新建建议没有未经确认实施。

## 课程脚手架

- [ ] 文件只位于 `source/_posts/learn-topic/<主题路径段>/` 的确认范围。
- [ ] 主题路径段、路线图名和文章名均为安全的单个名称；每个规范化目标的父目录严格等于课程目录。
- [ ] 文件名、标题沿用 `主题文档(序号)` 系列格式，description 为单行普通 YAML 字符串。
- [ ] 第二次确认后、占位写入前完成系列封面生成；项目最终只保留 `source/img/picgo-images/<主题路径段>-course-cover.png` 这一张 `1920 × 1080` PNG，修复验收问题时允许重试候选，全系列 `cover` 完全一致。
- [ ] 封面使用深蓝黑、青蓝紫霓虹的科技风格，包含准确的系列名称或清晰主题图标，中央 70% 安全区经缩略图和移动裁切检查后仍能识别课程主题。
- [ ] 封面没有随机风景、无关人物、动漫主体、长副标题、乱码、额外文字、水印、错误 Logo 或畸形图标；生成失败时没有回退到 Butterfly 随机封面。
- [ ] 每篇 `series_order` 是与中文序号一致的非重复正整数；正文使用 `{% course_series %}`，没有依赖标题或发布日期排序。
- [ ] 路线图可渲染且为公开状态，其他占位文章均有占位标记并为 `published: false`。
- [ ] 每个占位包含完整 Front Matter、职责、大纲、示例、视觉、FAQ、自测和来源计划。
- [ ] 完整文件先在隔离目录通过审计；真实目录先写入并读回未发布文章，路线图最后写入，没有默认公开中间态。
- [ ] 内容审计递归覆盖全部课程文章，没有路径冲突或遗漏。

## 单篇正文

- [ ] 当前只写一篇；批量模式也按知识依赖逐篇处理，动态事实已刷新，视觉预案已由用户确认。
- [ ] 正文包含机制、完整示例、验证、失败边界、踩坑、FAQ、自测和来源。
- [ ] 关系、流程、状态、层级和比较优先使用合适视觉，正文没有连续长段堆积。
- [ ] Mermaid 流程图方向与内容密度匹配：只有不超过 4 个主链节点、无复杂分支或子图且标签较短时使用 `LR`；其他情况使用 `TD/TB`，桌面与移动端均无文字压缩或横向溢出。
- [ ] 四类隐藏标签按教学目的使用，核心结论、命令和风险直接可见。
- [ ] Article Reviewer 无阻塞项；修复后已完成独立复查。
- [ ] H2/H3 简洁且按知识顺序组织；倒数第二个 H2 是 `常见问题`，最后一个 H2 是 `参考资料`。
- [ ] 公开文章没有“来源”“来源与核验范围”或“核验于 YYYY-MM-DD”等内部工作文案。

## 验证与状态

- [ ] 内容、标签和适用的资源审计通过。
- [ ] `hexo-blog-maintenance` 完整负责初稿及 Reviewer 修订后的审计、隔离 `--draft` 生成与浏览器验收。
- [ ] 目标路由完成桌面、移动端、明暗主题、展开交互、控制台和资源检查。
- [ ] 课程导航按知识顺序展示，当前篇、进度、键盘焦点和长标题状态清楚，桌面双列与移动单列均无溢出。
- [ ] 公开候选先在隔离副本完成普通生成、发布级审计和公开路由检查，才同步真实 `published: true` 及路线图目标行。
- [ ] 提升公开状态时已自动删除占位标记，没有把完整正文留在 `published: false` 等待用户提醒。
- [ ] 路线图中目标文章的状态、链接形态与前置关系作为整体更新并读回；失败时恢复为无链接的阻塞状态。
- [ ] 真实项目最终失败时已恢复未发布源码并用普通构建覆盖公开生成物；恢复失败时明确阻塞部署且未擅自清理。
- [ ] 路线图状态、文章 Front Matter 与实际证据一致；未验证和阻塞项单独说明。

## 权限与副作用

- [ ] 没有未经授权修改旧文章、主题、配置、依赖、外部仓库或发布状态。
- [ ] 没有执行未授权的清理、部署、commit、push、Issue 或 PR。
- [ ] 文章、来源、日志和截图不包含凭据、私人链接或敏感数据。
