## 你学完能够做什么

- 解释浏览器输入网址后，DNS、IP、TCP/QUIC、TLS 和 HTTP 如何协作。
- 看懂 IP 地址、子网掩码、端口、路由表和常见网络报文。
- 不靠背步骤，解释 TCP 三次握手、四次挥手、重传和拥塞控制。
- 区分 HTTP/1.1、HTTP/2、HTTP/3 及 HTTPS。
- 使用 `ping`、`dig`、`curl`、`traceroute`、`tcpdump` 和浏览器开发者工具排查网络问题。
- 回答常见计算机网络面试题，并能应对继续追问。
