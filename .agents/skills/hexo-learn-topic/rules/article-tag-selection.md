# 课程文章标签选型规则

本规则回答“这个正文块应该使用什么标签”。精确参数与可复制写法见 `references/butterfly-tag-usage.md`；当前注册能力、主题或插件源码与配置始终高于参考文档。

## 1. 当前标签能力快照

开始标签规划前运行：

```bash
node .agents/scripts/audit.mjs tags --json
```

然后读取 `_config.butterfly.yml` 中与标签运行有关的非敏感开关和资源键，只记录布尔状态、是否配置、资源所有者类型和验证结论，不复制 URL、凭据或配置片段。快照至少包含：

| 快照项 | 必须记录的事实 |
| --- | --- |
| 注册能力 | Butterfly、Tag Plugins Plus 与项目扩展的标签名和容器性 |
| 插件总开关 | `tag_plugins.enable`、优先级和 Markdown 渲染器状态 |
| 动态 Issues | `tag_plugins.issues`；关闭时禁止使用 |
| Plus 基础资源 | 样式、jQuery 和动画资源是否配置或使用插件默认外部资源 |
| Iconfont | `tag_plugins.CDN.iconfont` 是否实际提供 Symbol 资源；未配置时 `icon` 不可选 |
| Carousel | `tag_plugins.CDN.carousel` 是否配置，并在目标页验证脚本加载和交互 |
| GitHub 卡片 | `tag_plugins.CDN.ghcard_url` 是否配置自托管服务；未配置时标记使用插件默认第三方服务 |
| Butterfly 专项能力 | Mermaid、Chart.js、ABCJS 的启用和按页加载状态 |
| 外部依赖 | ghcard、徽章、远程图片、音视频、站点卡和资料卡的网络依赖与文字兜底 |

快照只包含标签名而缺少上述运行门禁时，Curriculum Reviewer 与 Article Reviewer 必须返回 `INSUFFICIENT_INFORMATION`。资源“已配置”不等于在线可用；使用相关标签的目标文章仍需真实页面验证。

## 2. 先确定读者任务

每个有意义正文块先记录一个读者任务，再选择一个主承载方式：

| 读者任务 | 首选承载 | 选择边界 |
| --- | --- | --- |
| 跟随概念故事理解选择与后果 | 按公开正文合同第 2.1 节标记的自然段，可穿插图表或图片 | 主线直接可见，不冒充新标签；结束后回到真实解释、映射和验证 |
| 直接看到结论、风险、适用条件 | `note`、`subnote` | 统一使用语义级别匹配的 `flat` 样式；只承载一个明确判断，不能成为所有解释段的默认外壳 |
| 理解概念的深入解释或查看长材料 | `folding` | 折叠前必须有可见摘要；命令、风险和恢复步骤不得只藏在内部；`hideToggle` 只用于章节末非复习自测 |
| 先思考再看答案 | `hideBlock`、`hideInline` | 分别用于完整解析和短答案；长期复习改用闪卡 |
| 在真正平行的方案之间切换 | `tabs`、`subtabs`、`subsubtabs` | 适用于平台、包管理器、语言、协议或互斥实现；连续步骤不能拆成页签 |
| 理解关系、流程、状态或时序 | `mermaid`、`timeline` | 图后给出文字结论和失败边界；不为装饰绘图 |
| 比较精确字段或真实数据 | Markdown 表格、`chartjs` | 静态字段优先表格；只有真实数值关系才用图表 |
| 对照多张界面或结果 | `gallery`、`galleryGroup`、`image`、`carousel` | 图片必须有文字上下文；核心结论不能只存在于图片 |
| 选择工具、入口或下一步操作 | `btn`、`btns`、`cell` | 按钮表示真实动作，不替代说明；按钮组只放同层级入口 |
| 识别术语、键位、状态或短强调 | `label`、`kbd`、`nota`、`bubble`、`emp` 等行内标签 | 只辅助句内阅读，不能替代块级解释承载 |
| 展示检查状态或可衡量进度 | `checkbox`、`radio`、`progress` | 必须来自真实状态或判断标准，不伪造可交互表单 |
| 展示项目、站点或扩展资料 | `ghcard`、`site`、`flink`、`link` 及分组标签 | 同时保留可读名称和普通 URL 语义，外部服务失败不影响主线 |
| 演示必须听到或看到的行为 | `audio`、`video`、`videos`、`score` | 只有主题确实需要媒体时使用，并提供文字替代或结果说明 |
| 进入长期复习队列 | `flashcard`、`flashcard_ref` | 真实高价值问题才使用，题数不设固定上限；遵守唯一 ID、卡组、优先级和全站解析文风合同 |
| 课程顺序与进度 | `course_series` | 系统课程唯一导航；不得改用 Butterfly `series` |

代码围栏、表格、列表、H2/H3 与必要结构连接可以保留普通 Markdown；概念故事仅按 `rules/published-article-contract.md` 第 2.1 节采用有界自然段。一个块同时包含多种任务时，先拆块，再分别选择承载方式。

## 3. 完整能力目录

### Butterfly 内置标签

| 标签 | 适用 | 不适用 | 可见性与降级 |
| --- | --- | --- | --- |
| `note` | 当前结论、风险、前提、兼容边界 | 连续包住每段普通解释，或用同一种级别表达所有语义 | 课程正文固定使用 `flat`；按下文语义矩阵选择级别，样式失效后正文仍完整 |
| `subnote` | 提示块内确有层级的补充判断 | 为颜色效果制造深层嵌套 | 不承担外层提示未说明的新风险 |
| `tabs` | 多平台、多安装方式、多语言或互斥方案 | 把先后步骤拆成切换页面 | 页签前直接说明选择标准；各页签自包含 |
| `subtabs` | 平行方案内真实的二级选择 | 一级 tabs 已能说明的内容 | 移动端仍可理解；外层页签提供上下文 |
| `subsubtabs` | 二级方案内不可避免的三级选择 | 为压缩篇幅制造深层嵌套 | 默认避免；真实页面证明键盘和移动端可用 |
| `mermaid` | 架构、依赖、状态机、调用链、时序 | 两个简单事实或图比文字更难读 | 图后保留文字结论和失败边界 |
| `timeline` | 生命周期、版本演进、按时间发生的阶段 | 无时间含义的普通步骤 | 每个节点有文字；样式失效仍保留顺序 |
| `chartjs` | 有来源的指标、比例、趋势与实验数据 | 主观估计或静态字段比较 | 同时写数据来源、单位和文字结论 |
| `gallery` | 多张截图或结果对照 | 单张图片和唯一答案 | Markdown 图片提供替代文本，正文给出结论 |
| `galleryGroup` | 多个图库入口 | 普通资料卡或正文步骤 | 名称、描述和链接不能只靠封面识别 |
| `hideInline` | 术语、命令、参数或一行答案 | 长解析、必要命令或风险 | 隐藏按钮失效时不能损失主线 |
| `hideBlock` | 先推演后揭晓的完整解析 | 长期复习题和必要恢复步骤 | 问题与任务直接可见，解析可揭晓 |
| `hideToggle` | 章节末不进入长期复习队列的完整自测 | 概念说明、长配置、日志或普通补充 | 自测任务直接可见，隐藏区不使用标题层级 |
| `btn` | 单一官方入口、下载或可执行动作 | 普通引用列表 | 按钮文字说明动作，链接失效不影响知识主线 |
| `inlineImg` | 不承担信息的行内图标或表情 | 需要 `alt` 的核心示意图 | 加载失败不影响句义 |
| `label` | 极短状态、类型或等级 | 用多个标签代替完整判断 | 标签外的句子保留完整含义 |
| `flink` | 需要友链式字段的站点集合 | 普通参考资料 | 名称、描述和 URL 可识别，头像仅增强 |
| `score` | 音乐、音频或格式课程的 ABC 乐谱 | 与主题无关的装饰 | 提供文字说明或可读乐谱源码 |
| `series` | 非系统课程的 Butterfly 通用系列 | 系统课程 | 系统课程必须使用 `course_series` |

### Tag Plugins Plus

| 标签 | 适用 | 不适用 | 可见性与降级 |
| --- | --- | --- | --- |
| `tip` | 当前项目已注册，供非课程内容核对历史用法 | 公开课程正文的任何提示、技巧、注意或边界 | 课程正文禁止使用；改用语义匹配的 `note <级别> flat`，长补充改用 `folding` |
| `folding` | 概念深入解释、长代码、日志、完整配置 | 隐藏必要命令、风险或恢复步骤 | 折叠前有摘要；可用 `open` 默认展开，原生 details 无脚本仍可操作 |
| `btns` | 多个同层级工具或文档入口 | 连续步骤和普通链接列表 | 组标题或上下文直接说明选择依据 |
| `cell` | `btns` 内单个入口 | 脱离按钮组承担正文解释 | 文本可识别，图标或图片只是增强 |
| `checkbox` | 已核验检查项和布尔状态 | 冒充可提交表单 | 状态同时用文字表达 |
| `radio` | 已确定的互斥选择或推荐项 | 让读者误以为能提交选择 | 选择依据和选中项直接可见 |
| `progress` | 有真实分母的进度或完成度 | 主观百分比 | 同时说明计算口径和数值文本 |
| `image` | 需要 `alt` 的块级截图或示意图 | 只有图片才能表达的答案 | 提供准确 `alt` 和正文结论 |
| `inlineimage` | 装饰性行内图 | 需要替代文本的核心图 | 加载失败不影响句义 |
| `carousel` | 多状态截图轮播 | 单张图或必须并排精确比较 | 页面唯一 ID；提供图注和文字结论，验证脚本资源 |
| `link` | 单个资料卡 | 正文内部普通跳转 | 标题和 URL 在图片失败时仍可理解 |
| `linkgroup` | 同一用途的资料卡集合 | 混合无关资源 | 分组标题、卡片标题和 URL 保留语义 |
| `ghcard` | GitHub 用户或仓库增强卡 | 项目机制说明或唯一入口 | 保留普通仓库链接；标记默认第三方统计服务依赖 |
| `ghcardgroup` | 多个同类 GitHub 卡片 | 单一卡片或无比较目的的堆叠 | 组外说明比较目的，卡片失败仍有链接 |
| `site` | 带截图和说明的站点卡 | 替代工具选择依据 | 名称、描述和 URL 可读，截图仅增强 |
| `sitegroup` | 同一用途的站点集合 | 混合无关站点 | 组标题直接可见，每个站点保留文字信息 |
| `kbd` | 快捷键和真实按键组合 | 普通命令或抽象操作 | 文字内容本身可读 |
| `nota` | 短术语及其注释 | 核心定义只放悬浮层 | 首次出现仍在正文给出必要定义 |
| `bubble` | 短术语的补充说明 | 移动端必须悬停才能理解 | 主句完整，气泡只增强 |
| `p` | 插件段落样式确有语义 | 用样式伪造标题层级 | 文本直接可见，不计块级解释覆盖 |
| `span` | 短行内样式 | 整段正文或伪标题 | 去掉样式后句义不变 |
| `u` | 必要的短下划线强调 | 可用语义文字直接说明时滥用 | 不以颜色或线条作为唯一线索 |
| `emp` | 单个关键短语 | 替代完整结论 | 去掉样式后句义完整 |
| `wavy` | 标记易混淆或需注意的短语 | 长段警告 | 同时用文字说明原因 |
| `del` | 展示废弃或错误写法 | 普通修订记录 | 同时给出当前替代项 |
| `psw` | 剧透式短内容 | 密码、令牌和其他秘密 | 只是视觉遮罩，敏感信息不得写入源码 |
| `icon` | 已配置 Symbol 资源中的装饰图标 | Iconfont 未配置或图标承担唯一信息 | 快照确认资源可用；旁边保留文字 |
| `bdage` | 有事实来源的构建、版本或兼容徽章 | 把徽章当作正文证据 | 同时写状态含义；远程徽章失败不影响判断 |
| `referto` | 正文中的页内引用点 | 没有对应来源 | 摘要直接可读，ID 页面内唯一 |
| `referfrom` | 与引用点对应的来源 | 孤立来源或 ID 不匹配 | 标题和 URL 直接可读 |
| `audio` | 声音本身参与教学 | 无文字替代的讲解 | 提供文字说明、转写或等价结果 |
| `video` | 动态操作或视觉结果参与教学 | 只用视频解释主线 | 提供步骤、字幕或文字结果 |
| `videos` | 多个同类视频对照 | 单个视频和无比较目的的堆叠 | 组外说明观看任务，各项有文字说明 |
| `poem` | 诗词或需保留排版的文本作品 | 普通技术正文 | 内容本身是可读文本，不依赖样式 |
| `issues` | 配置启用后的动态 Issues 数据 | 当前关闭状态或无外部 API 授权 | 当前禁止使用；启用后仍提供静态说明和失败兜底 |

### 项目扩展

| 标签 | 适用 | 不适用 | 可见性与降级 |
| --- | --- | --- | --- |
| `flashcard` | FAQ、面试题、自测中的长期复习题 | 普通补充说明或无复习价值的问题 | 题面、精简回答和可独立理解的详细解析完整；抽象或复杂题使用合适的 Markdown 辅助表达；遵守唯一 ID、单一卡组和优先级合同 |
| `flashcard_ref` | 跨文章复用已有题目 | 复制或覆盖原题内容 | 只引用原始定义 ID；目标缺失时发布门禁阻断 |
| `course_series` | 课程导航、当前篇与稳定篇序 | 普通文章和手写重复导航 | 系统课程唯一导航，依赖 `series_order`；导航失败不影响正文知识 |

## 4. 提示层级与视觉约束

公开课程的直接可见提示统一使用 Butterfly `note <级别> flat`。级别表达信息性质，不用于交替配色：

| 写法 | 适用语义 | 不适用 |
| --- | --- | --- |
| `{% note info flat %}` | 中性概念、背景、范围、前置条件 | 风险、推荐结果或不可逆后果 |
| `{% note primary flat %}` | 核心原则、关键判断、需要优先记住的结论 | 普通补充说明或每节固定开场 |
| `{% note success flat %}` | 推荐实践、成功标准、已满足条件后的结果 | 尚未验证的预期或一般说明 |
| `{% note warning flat %}` | 常见失败、兼容限制、容易误用但可恢复的风险 | 数据丢失、安全事故或不可逆操作 |
| `{% note danger flat %}` | 安全风险、数据丢失、破坏性或不可逆后果 | 普通报错、一般注意事项或视觉强调 |

- 级别必须写作 `warning`，不得写成 `waring`；主题当前支持 `default`、`primary`、`info`、`success`、`warning`、`danger`，课程只在上述明确语义中使用后五种。
- 课程提示块固定使用 `flat`，不使用 `modern`、`simple`、`disabled` 或自定义大色块；默认图标可以保留，只有图标造成误导时才使用 `no-icon`。
- `subnote` 仅用于提示块内部确有从属关系的第二个判断，并沿用同一套级别和 `flat` 样式；能拆成相邻独立块时不嵌套。
- 长原理、完整配置、日志和次要案例使用 `folding`。折叠前直接写出摘要和阅读理由，必要命令、风险、恢复步骤与验证结果保持可见。
- 多平台、多安装方式、多语言或互斥实现使用 `tabs`；连续步骤、先后阶段或共同前提不拆成页签。
- Tag Plugins Plus `tip` 即使当前已注册，也不得出现在公开课程正文或可复制的课程模板、示例中。

## 5. 正文块标签计划

文章地图和占位合同中的每个正文块至少记录：

| 字段 | 要求 |
| --- | --- |
| 读者任务 | 只写一个动作或判断，例如“比较两种安装范围” |
| 核心内容 | 本块必须直接交付的结论或能力 |
| 主承载 | 一个块级标签、图表、表格、代码或列表 |
| 选择理由 | 说明该承载如何降低理解成本 |
| 可见性 | 标记哪些信息必须直接可见，哪些允许展开 |
| 降级 | 交互、图片、脚本或外部网络失败时仍能读到什么 |
| 验证状态 | 构建、桌面/移动、明暗主题和交互检查结果 |

不要预先规定每篇必须出现几个标签。连续三个以上解释块选择同一种标签时，重新检查是否存在：可以改成流程图的关系、适合页签的平行方案、应折叠的长补充、适合表格的精确比较，或本来就应该删减的重复文字。复查后仍使用同一标签时，在标签计划中写明共同语义。

## 6. 信息可见性

- 直接可见：主结论、必要命令、安全风险、兼容条件、错误恢复、验证结果。
- 可以折叠：深入原理、完整日志、完整配置、长脚手架和额外案例使用 `folding`；章节末非复习自测使用 `hideToggle`。
- 可以依赖交互切换：平行方案各自专属的命令、风险、恢复和验证可以留在对应的自包含页签；跨方案共同的前提、选择标准、风险和成功证据必须在页签前直接展示。
- 可以依赖外部资源：扩展阅读和增强媒体；主线知识、下载校验和故障判断必须有本地文字兜底。
- 不得公开：密码、令牌、私人链接和未经处理的用户输入；`psw` 只是视觉遮罩，不是安全机制。

## 7. 验收

1. `audit.mjs tags` 确认注册、容器、插件开关和 `issues`；标签能力快照另外确认 Iconfont、Carousel、ghcard、Butterfly 专项能力与外部资源状态。
2. `content --release` 确认有意义解释块具有承载角色。
3. Article Reviewer 检查公开正文是否误用 `tip`，`note` 是否固定为 `flat` 且级别符合语义，是否形成 `note info` 单一化，以及是否错误隐藏核心信息。
