# 调研与来源规则

## 1. 来源优先级

1. 官方文档、规范、源码、发布说明和维护者材料；
2. 官方仓库的 Issues、Discussions、Pull Requests 与贡献文档；
3. Stack Overflow 等可追溯回答、复现和时间的技术问答；
4. CSDN、知乎、招聘网站等用于发现高频疑问、踩坑和面试关注点；
5. 大模型只补充真实来源尚未覆盖的提问角度，不充当动态事实来源。

社区票数、搜索排名和转载次数不等于正确。版本、API、配置、安全和源码机制必须回到当前一手资料核验。

## 2. 来源记录

每条进入路线或文章的关键来源记录：标题、最终 URL、来源类型、核验日期、适用版本或 Commit、支撑的知识点。链接不可访问、内容冲突或版本不明时标记缺口，不把摘要当作全文。

只做必要转述和短引用；保留原链接，不复制问题、答案、文章或官方文档的大段正文。

## 3. 官方能力全集

路线设计前先冻结一个有限、可复算的枚举合同，并把合同作为入口 manifest 保存。manifest 必须记录主题类型、语言或运行器、目标版本或完整 Commit、每个官方入口的最终 URL 或仓库路径、入口类别、遍历终点与不可访问状态。没有 manifest 时不得声称建立了全集。

### 3.1 枚举边界

- 软件库或框架：以目标语言绑定在冻结版本中的官方 generated API 声明面为当前 API 左表；对每个公开类、对象、模块入口和方法逐一枚举公开成员、属性以及公开签名参数（不能只列方法名或手写“常用参数族”）；补入同版本官方配置参考、CLI reference、事件 reference 和 Guides 目录中的独立公开能力。仅由基础事件发射器继承、未在目标类官方 API 页面声明的 `on`、`once`、`remove_listener` 等实现辅助方法，应在入口 manifest 中明确排除，不能一边排除一边声称遍历了全部公开运行时属性；具有官方事件入口的对象仍须以事件 Guide、类页面或正文证据覆盖。Release Notes 只用于确认该冻结版本新增、弃用或改名，不把早于冻结版本且已移除的历史接口无限并入当前集合。
- 语言或规范：以冻结版本的官方参考目录、规范章节、语法目录和标准库索引为左表，遍历到其末级可链接条目；说明性 Guide 只补入未被参考目录表示的独立能力。
- 开源项目：以冻结 Commit 的公开 CLI 命令与选项、用户可配置键、维护者声明的扩展点、公开入口模块、核心调用链节点和维护者文档末级目录为左表；内部辅助函数不因可搜索到而自动进入全集。

入口 manifest 必须逐项声明采用哪个入口、遍历到哪里以及为何结束。入口不存在时记录“不适用”，入口应存在但无法访问时记录缺口并停止进入路线确认；Reviewer 不自行扩张为互联网搜索范围。

### 3.2 稳定标识与去重

- API 使用 `语言绑定:对象.成员`；事件使用 `语言绑定:对象.event:名称`；配置使用 `配置域:key.path`；CLI 使用 `cli:命令 --选项`；Guide 使用 `guide:官方路径段`；规范、语言与项目条目使用 manifest 中冻结的规范路径或仓库公开路径。
- 同一成员的重载和纯类型差异合并为一项；同步/异步会改变调用、等待、错误传播或取消模型时必须使用不同稳定标识，分别处置并提供证据。只有语义与调用模型均相同的别名镜像才可合并，且每个镜像必须作为强制子项记录，Reviewer 逐子项对账。每个公开方法的签名参数也必须用稳定的 `option:对象.成员.参数` 标识单列；参数是否只在某一调用模型存在必须在强制镜像字段中如实记录，不能因为“默认值常用”而省略。
- 重导出、继承成员和别名按规范定义者只保留一行；别名在强制子项列出。实验能力保留并标记实验；平台特定能力保留并标记平台。当前已弃用但仍可用的接口留在当前集合；已移除接口只在确有现实迁移需求时进入单独的“旧接口补充集”，不计入当前全集，但必须进入旧接口迁移映射，记录替代项、主文章、章节、来源和正文证据。

每项记录稳定标识、对象或主题、版本状态、来源 URL、适用版本和备注。官方资料冲突时保留缺口，不自行选择方便写作的版本。

### 3.3 集合门禁

能力全集是 manifest 所界定的当前官方范围，不是“穷尽互联网”的声明。官方稳定标识集合与覆盖处置账本稳定标识集合必须完全相等：`官方仅有 = 0`、`账本仅有 = 0`、`重复 = 0`、`未处置 = 0`。五类数量只统计匹配后的唯一账本行，不能用总数相等替代集合相等。

## 4. 研究完成条件

- 学习对象、当前版本、硬前置、边界和可验证成果均已核验；
- 每个路线阶段有至少一项一手来源；
- 高频问题能追溯到真实社区材料，答案已用当前资料复核；
- 官方能力全集有版本、入口 manifest、遍历边界、来源、稳定标识和集合摘要；
- 无法核验的细节从必修路线移出并显式标记；
- 不声称穷尽互联网，以覆盖处置账本和来源缺口说明有限范围。

## 5. 开源项目边界

开源项目固定 canonical URL、ref、完整 Commit、许可证和核验日期。临时只读 checkout 只用于事实核查；持久 clone、依赖安装、命令执行、源码修改和外部贡献遵守目标环境规则与独立授权。
