计算机网络(一)入门路线

发表于2026-03-01|更新于2026-08-27|Learn Topic计算机网络
|总字数:862|阅读时长:2分钟|浏览量:

这是一门从分层、寻址、传输、HTTP 到现代 Web 和网络排障的系统课程。每篇文章都沿着“概念图 → 字段/状态 → 可复现实验 → 闪卡”推进，先建立可观察的模型，再回答面试题。

入口篇只负责建立网络学习坐标；协议细节、实验和面试闪卡分别放在对应主题文章。

课程目标

  • 用分层、寻址、传输和应用语义拆解网络现象。
  • 按局域网 → IP → UDP/TCP → HTTP → HTTPS/现代 HTTP → 排障建立可观察的心智模型。
  • 通过图表、抓包和闪卡把高频机制（HTTP、TCP、三次握手）变成可复述、可验证的知识。

前置条件

不要求网络工程经验；准备可运行 curl、浏览器开发者工具和一个可抓包的本地环境。课程实验使用环回地址、虚构数据和可丢弃的网络命名空间，不触碰真实凭据或生产流量。

学习路径

主线先理解帧、MAC、ARP 和广播边界，再学习 CIDR、路由和 DNS；接着进入 UDP/TCP 的端点、状态、可靠性和三次握手；最后用 HTTP、TLS、QUIC、浏览器工具和抓包把协议语义落到真实证据。进阶路线与综合实战用于把这些模型组合起来。

开始学习

开始学习时，打开“网络分层与局域网”，用一个同网段通信例子观察数据如何经过帧、MAC、交换机和 ARP；后续再把同一条观察链扩展到 IP、TCP、HTTP 和现代 Web。入口文章只提供坐标，不承担协议细节和面试答案。
