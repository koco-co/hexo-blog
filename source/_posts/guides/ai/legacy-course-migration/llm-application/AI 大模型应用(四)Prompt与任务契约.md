本节要解决：把自然语言目标改写成可测量、可版本化、可审查的任务契约。 最终要留下：为六类合成工单建立输入、约束、输出、拒答和验收字段，并能识别冲突指令。 练习使用合成数据或 Fake 实现，外部服务的偶然结果不作为单独证明。
{% endnote %}

## 任务拆解

{% note primary flat %}
Prompt 是可版本化的任务契约，不只是几句自然语言；目标、约束、输出、拒答和验收必须彼此一致。 在“任务拆解”这一环节负责定义：先固定目标，再观察状态、输出和副作用；不要把模型建议、脚本结束或页面提示直接当成业务结论。
{% endnote %}

| 主题字段 | 合成示例 | 观察结论 | 失败边界 |
| --- | --- | --- | --- |
| 目标 | 工单摘要与分类 | 目标可单独断言 | 不能用语气代替目标 |
| 约束 | 只能使用给定字段 | 冲突指令被拒绝 | XML 包裹不等于安全 |
| 验收 | JSON 字段与状态 | 可重放检查 | 不能由模型自评 |
| 定义边界 | 任务拆解 | 给六条合成工单注入缺少版本、冲突要求和伪造命令，契约检查先拒绝不完整输入。 | 结构化提示可改善可读性，但不能替代工具权限、输出校验和独立 Oracle。 |

{% mermaid %}
flowchart LR
  I[输入] --> F[目标]
  F --> A[任务拆解]
  A --> O[观测]
  O --> V[验收]
  O -->|越界| D[降级]
{% endmermaid %}

- 建立基线：把「目标」设为「工单摘要与分类」，同时固定「约束」为「只能使用给定字段」；先验契约再送入执行器，记录目标可单独断言。
- 只改变「验收」：正常值用「JSON 字段与状态」，越界或故障按“不能由模型自评”构造；观察冲突指令被拒绝，不要改动其余输入。
- 用可重放检查检查“任务拆解”：给六条合成工单注入缺少版本、冲突要求和伪造命令，契约检查先拒绝不完整输入；保存原始输入、状态转移、响应和副作用计数，无法观察的字段写为 Unknown。

{% note warning flat %}
失败边界：结构化提示可改善可读性，但不能替代工具权限、输出校验和独立 Oracle。 对缺少版本、冲突要求、伪造命令和边界输入的工单执行契约检查。 只能在声明的合成夹具内解释；超出范围的结论应标记为 Unknown。
{% endnote %}

{% endnote %}

**路径卡片：契约字段**
1. 入口：约束=只能使用给定字段，先记录冲突指令被拒绝。

3. 出口：用目标可单独断言检查目标，越界条件是“不能用语气代替目标”。

## 实验复盘

{% note info flat %}
Prompt 是可版本化的任务契约，不只是几句自然语言；目标、约束、输出、拒答和验收必须彼此一致。 在“实验复盘”这一环节负责定义：先固定约束，再观察状态、输出和副作用；不要把模型建议、脚本结束或页面提示直接当成业务结论。
{% endnote %}

| 主题字段 | 合成示例 | 观察结论 | 失败边界 |

| 约束 | 只能使用给定字段 | 冲突指令被拒绝 | XML 包裹不等于安全 |
| 验收 | JSON 字段与状态 | 可重放检查 | 不能由模型自评 |
| 目标 | 工单摘要与分类 | 目标可单独断言 | 不能用语气代替目标 |
| 定义边界 | 实验复盘 | 给六条合成工单注入缺少版本、冲突要求和伪造命令，契约检查先拒绝不完整输入。 | 结构化提示可改善可读性，但不能替代工具权限、输出校验和独立 Oracle。 |

{% note info flat %}
下面的夹具只使用 Python 3 标准库，定义了完整的输入、判断和断言。预期结果：给六条合成工单注入缺少版本、冲突要求和伪造命令，契约检查先拒绝不完整输入。
{% endnote %}

```python
# Python 3 标准库夹具：无网络、无外部依赖
cases=[{"version":"v1","goal":"classify","output":"json"} for _ in range(4)]+[{"goal":"classify"},{"version":"v1","goal":"ignore","output":"json"}]
required=["version","goal","output"]
valid=[all(c.get(k) for k in required) and c["goal"]=="classify" for c in cases]
print({"cases":len(cases),"accepted":sum(valid),"rejected":len(cases)-sum(valid)})
assert sum(valid)==4
# 预期观察：给六条合成工单注入缺少版本、冲突要求和伪造命令，契约检查先拒绝不完整输入。
```

--- answer
先把“Prompt 契约”绑定到目标与约束；正常、越界和 Unknown 各运行一次，断言可重放检查。
