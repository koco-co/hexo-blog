## 文章职责

- 唯一要解决的问题：把任务摘要、事实证据、未决风险和环境重查写成交接包。
- 可观察成果：能在新会话或新 Agent 中恢复工作，而不是只复制一句摘要。
- 明确不承担：不重复前置文章的通用定义；跨主题扩展交给对应后续文章。

## 内容边界

- 进入条件：完成 B07 的相关实验与边界判断。
- 覆盖条目：交接字段、事实链接、环境重查、续作边界
- 失败边界：中断后交接合成任务，重新检查 cwd、版本、dirty 状态和未完成步骤。 还必须说明不适用条件、降级路径和不能由本篇单独证明的结论。
