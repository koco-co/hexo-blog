{% note info flat %}
这是一门以功能测试用例设计为主线的测试基础课程。课程先建立测试原理、研发协作和需求评审的共同语言，再重点训练等价类、边界值、判定表、状态迁移和场景化用例设计，最后补充探索式、白盒、非功能、缺陷交付与自动化策略。
{% endnote %}

![测试基础课程封面](/img/learn-topic/testing-basics/course-cover.png "测试基础课程封面")

{% course_series %}

## 课程目标

{% note info flat %}
- 能把需求规则拆成测试条件、数据、步骤、预期和覆盖理由。
- 能根据输入域、边界、规则组合、状态和业务流程选择黑盒测试方法。
- 能在面试场景中先澄清假设，再给出功能主线、代表用例、未覆盖风险和追问方向。
- 36 道场景题以功能用例为主，安全、性能、兼容、国际化、易用性和无障碍作为补充视角。
{% endnote %}

## 前置条件

- 不要求编程基础；纸笔或表格即可开始。
- 需要能读懂简单的业务规则、输入约束和状态变化；白盒部分会补齐必要代码阅读知识。
- 所有产品案例均为教学假设；客服聊天、红包和杯子题会明确规则，不冒充真实厂商产品规格。

## 开始学习

- 先建立测试原理和质量证据的共同语言，再进入可执行、可复核的用例表格。
- 功能黑盒用例设计是课程主线：先写完整用例，再做输入、规则、状态和陌生场景训练。
- 场景题回答统一遵循“澄清假设 → 拆分功能 → 选择模型 → 设计代表用例 → 检查遗漏 → 说明取舍”。
- 每篇正式正文会给出可复核的预期结果；不把用例数量当作覆盖完整的证明。
